# Tài liệu và code tham khảo

Các thuật toán HUIM còn lại (ULB, HUI-Miner, R-Miner, FHMDS, UP-Growth), cấu trúc dữ liệu và datasets Chess/Connect/Accidents vẫn liên quan hướng nghiên cứu nên được giữ để tham khảo. Một số source từ cấu trúc cũ chưa đủ phụ thuộc để biên dịch; thư mục này không phải bộ nộp giữa kỳ hoặc bản build đang dùng.

Bản Java đang phát triển và chạy độc lập nằm ở **../midterm/**. Không sửa reference để rồi diễn giải như đã sửa phiên bản đang dùng.

notes/ giữ các ghi chú kế hoạch, phân tích và kịch bản trước khi tách folder, theo trạng thái thời điểm viết. Lệnh/path cũ trong đó là lịch sử; hướng dẫn hiện tại nằm tại ../midterm/README.md. Nội dung có thể dùng khi tiếp tục viết report/slide sau khi kiểm tra trạng thái mới nhất.

Các header bản quyền SPMF được giữ nguyên. Giấy phép GPL của SPMF có tại ../midterm/LICENSE_SPMF_GPL3.txt.
